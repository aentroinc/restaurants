# 00 — マスタープラン: 40 → 100 点までの設計図

> 「日本の外食専用 Palantir」を 100 点（業界デファクト候補）まで持ち上げるための上位設計。
> 各領域の深掘り仕様は `01-08`、横断仕様は `09-11`、事業設計は `12`、実行計画は `13-14`。

---

## 1. 100 点の定義

「100 点 = Palantir Foundry 相当の汎用性 + 外食バーティカルでの絶対優位」。

判定軸は3つ：

| 軸 | 100点条件 | 採点詳細 |
|----|----------|---------|
| **製品** | Foundry の Ontology / Lineage / Workspace / Workflow / Audit / DQ がすべて稼働、かつ動的編集可能 | `SCORE.md` 領域 01-06, 09-11 |
| **顧客** | 外食上位50社のうち 5社以上が本契約、年間 1社以上の業界デファクト事例 | `SCORE.md` 領域 07, 12 |
| **業界深掘り** | レシピ/法令/HACCP/FC会計/商圏 が日本の外食業界基準を超えるカバレッジ | `SCORE.md` 領域 08 |

**90 点未満では「業界向け汎用 BI」、それ以上で「業界 OS（オペレーション基盤）」**。

## 6. 並列実行の組織モデル

100 点を 12 ヶ月で達成するには **延べ 60 人月相当の作業** を 5〜6 ヶ月の wall-clock に圧縮する並列が必須。

### 推奨チーム構成（コア 12 人）

| チーム | 人数 | 主担当領域 |
|-------|------|-----------|
| Platform Core | 2 | 01, 04, 09 (multi-tenancy / perf / observability) |
| Integration | 2 | 02 (Smaregi → Air → Square 順)、CDC / scheduler |
| AI / Data Science | 2 | 03, 10 (LLM, eval, RAG, forecasting) |
| Identity / Security | 1 | 05, 11 (SSO / RBAC / SOC2) |
| Infra / SRE | 1 | 06, 09 (Terraform / Helm / OTel / SLO) |
| Vertical / Domain | 2 | 08 (Recipe / HACCP / FC / Huff) |
| Frontend Lead | 1 | 全UIの統合 + design system |
| Customer Success / FE | 1 | 07 パイロット常駐 + Meeting Pack 自動化 |

役員/事業:
- CTO（製品全体統括）
- VP Eng（クロスチーム調整）
- VP Sales / CS（12 担当）
- CEO（業界 KOL ネットワーク開拓）

### スキル要件
- Platform Core: Postgres / SQLAlchemy / JSONB / pgvector の上級
- Integration: OAuth / httpx / レート制限 / CDC（debezium 経験あれば加点）
- AI/DS: Anthropic SDK / pgvector / 統計的有意性検定
- Security: SAML 2.0 / OIDC / OPA / 個情法 / SOC2 監査経験
- SRE: Terraform / Helm / OpenTelemetry / IaC
- Vertical: 外食産業経験 必須（元 SV / FC本部 / メーカー営業）

## 9. 価値仮説（投資対効果の根拠）

100 点製品を年間 ¥30M-100M で売れる想定。導入企業の価値:

| 価値項目 | 単店舗あたり年間 | 50店舗チェーン | 500店舗チェーン |
|---------|----------------|---------------|---------------|
| 廃棄削減 (-20%) | ¥600K | ¥30M | ¥300M |
| 人件費最適化 (-1.5pt) | ¥1.2M | ¥60M | ¥600M |
| 客単価UP (+2%) | ¥800K | ¥40M | ¥400M |
| 出店ROI改善 | – | ¥50M (10店分) | ¥500M (100店分) |
| 経営工数削減 | – | ¥10M | ¥100M |
| **合計** | **¥2.6M** | **¥190M** | **¥1.9B** |

→ ¥30M-100M の年間ライセンスは ROI 5-20x で正当化可能。詳細は `12-gtm-pricing-org.md`。

## 10. 採点更新ルール（運用）

- 加算は **Evidence (証拠) があるもののみ**（`14-acceptance-evidence.md` 参照）
