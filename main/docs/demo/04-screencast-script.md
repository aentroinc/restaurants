## 共通の収録ガイド

- **カーソル軌跡を遅く**: 視線誘導
- **クリック効果音**: あり (極小)
- **重要数字はカットイン**: 1 秒静止画オーバーレイ
- **BGM**: なし (ナレが主)
- **字幕**: 日英両方ベイクイン (海外展開用)

## 別トラック: ナレーション 1 ファイル化のコツ

```
sukiya-pitch-narration.mp3 (各動画用)
sukiya-pitch-bgm.mp3 (-22 LUFS)
sukiya-pitch-screenshare.mov
```

最終 mux:
```bash
ffmpeg -i screen.mov -i narr.mp3 -i bgm.mp3 \
  -filter_complex "[2:a]volume=0.15[bg];[1:a][bg]amix=inputs=2[a]" \
  -c:v copy -map 0:v -map "[a]" out.mp4
```
