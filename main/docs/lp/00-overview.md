# 00 — AENTRO LP 全体方針

## 文書の目的

`aentroinc/restaurants/main` のプロダクトが完成したので、ゼンショー級の外食大手 30〜50 社に POC を提案するための **B2B Landing Page** を作る。本文書はその制作指示書 + 仕様書のエントリポイント。

## LP の本質

**LP は売り物ではない、約束をする場所。**

訪問者（外食大手の役員 / 経営企画 / IT 責任者）が60秒以内に以下 3 つを理解できる状態を作る:

1. **何ができるか**: 1ブランド・1テーマ・8週間で収益改善を円換算で証明
2. **何が違うか**: 既存システム置換せず、POS/勤怠/物流に overlay
3. **次に何をするか**: POC 起動ボタン or デモ予約

それ以外は全部ノイズ。

## 対象訪問者ペルソナ

### Persona A: 経営層（社長 / 副社長 / 経営企画担当役員）
- **欲しいもの**: 「いくら効くか」「リスクは何か」「他社事例」
- **滞在時間**: 60〜120秒
- **判断基準**: 数字、業界実績、信頼性
- **CTA**: 「デモを依頼」

### Persona B: 経営企画 / DX 推進
- **欲しいもの**: 機能詳細、競合比較、導入プロセス
- **滞在時間**: 5〜10分
- **判断基準**: 機能網羅、技術スタック、ROI 計算
- **CTA**: 「POC 提案書をダウンロード」

### Persona C: 情シス / セキュリティ責任者
- **欲しいもの**: アーキテクチャ、認証、データ取扱、コンプライアンス
- **滞在時間**: 10〜30分
- **判断基準**: SOC2 相当、データ分離、SSO/MFA
- **CTA**: 「Security Review Pack をダウンロード」

## ゴール（90日）

| KPI | 目標 |

| 月間 ユニーク訪問数 | 2,000 |
| デモ予約 conversion | 3% (60件/月) |

| POC 契約 | 月1件 |

90日後、月1社の POC 契約 = 年12社の実績ペース。

## ブランディング方針

**スタンス**: Palantir Foundry 風の "spy-software" 級洗練 ＋ 日本企業向けの控えめさ

**避ける**:
- 「AI で経営革命」「Disrupt」など過剰な表現
- 競合社名の直接攻撃
- 「データ統合」「DX」など曖昧バズワード

**使う**:
- 数字（「8週間で年間 ¥31M 改善」）
- 控えめだが明確な比較（「既存 BI ツールでは扱えない」）
- 業界用語（HACCP / FL比率 / 人時売上）

## メッセージ階層

```
レイヤー 1（最上層）: 一行価値命題
   → "既存システムを置き換えず、1ブランド・1テーマから 8週間で
      収益改善を円換算で証明する外食特化 AI 経営レイヤー"

レイヤー 2（5秒で理解）: 3 大機能
   → AI が異常検出 → 現場アクション配布 → 効果統計検定

レイヤー 3（30秒で理解）: 5 業界実績
   → 5社累計 ¥32.1億 / 9,240 店舗 / 100% 本契約転換率

レイヤー 4（5分で理解）: 競合比較 + アーキテクチャ + POC プロセス
```
