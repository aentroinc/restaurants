# Kanjo モックアプリ 取扱説明書

> CoCo Spice(48店舗カレーチェーン)を想定した外食経営AI SaaSのインタラクティブモック

---

## 起動方法

```bash
cd kanjo
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開く(ポートが使用中の場合は別ポートが表示される)。
スマホサイズ(横幅430px以下)で見るのが正しい表示。PCの場合はChromeのデバイスツールでiPhone 14等を選択。

---

## ロール切り替え

画面上部の **経営 / エリア / 店長** タブで切り替える。
切り替えると以下が全て変わる:

- ホーム画面の内容
- 下部ナビゲーションの項目
- おしらせ(通知)の内容とLINEプレビュー
- 各ページの情報密度と言葉遣い

---

## ロール別ガイド

### 経営(社長 / 山本誠一)

全社を俯瞰する画面。EBITDA・P/L・ROIなどの経営指標が中心。

| ナビ | ページ | 見どころ |
|---|---|---|
| 全社概況 | `/` | ライブティッカー、EBITDA Impactカード(ダーク)、エリアドリルダウン |
| 損益 | `/report` | 月次P/L、コスト構成比バー、エリア別実績テーブル、PDF/Excel出力 |
| AI効果 | `/ai-impact` | 改善内訳5項目、EBITDA推移チャート、ROI 16.7x、モジュール別詳細 |
| 店舗 | `/stores` | 売上順/原価率順/エリア別タブ切り替え、店舗タップで詳細展開 |
| 設定 | `/settings` | スマレジ連携詳細(遅延2.3秒、同期14万件)、POS接続テスト |

**ホーム画面の操作:**
- ライブティッカー → 4秒ごとにKPIが切り替わる(自動)
- EBITDA Impactカード → 「改善内訳 / EBITDA推移 / コスト」タブで切り替え
- P/L → 「サマリー / コスト構成」タブで切り替え
- エリア行をタップ → 配下店舗がスライドで展開
- 下部のクイックリンク → 各詳細ページへ(リピート率・口コミ・デリバリー・販促)

### エリアマネージャー(中村恵 / 東京23区担当)

担当エリア3店舗の比較が中心。◎△✕で直感的に判断できる。

| ナビ | ページ | 見どころ |
|---|---|---|
| エリア | `/` | ライブティッカー、◎△✕スコアカード、店舗タップで詳細展開 |
| 店舗くらべ | `/stores` | 売上順/原価率順/エリア別の3タブ |
| シフト | `/shift` | シフト表、不足警告、スタッフ一覧 |
| ロス | `/waste` | カテゴリ別ロス、エリア別比較、半年推移 |
| 設定 | `/settings` | POS連携ステータス |

**ホーム画面の操作:**
- 店舗くらべ → 「全体 / 原価率 / 売上」タブで切り替え
- 店舗カードをタップ → 目標/原価/人件費/ロスの4指標が展開
- 「気をつけるところ」「いまのおしらせ」「シフト」「LINE」 → タップで開閉

### 店長(田中太郎 / 渋谷センター街店)

今日の自店舗だけ。大きな数字とアクションボタンが中心。

| ナビ | ページ | 見どころ |
|---|---|---|
| ホーム | `/` | ライブ売上カウンター(数秒ごとに+チャリン)、ゴールバー、やることリスト |
| 見込み | `/forecast` | 明日の来客予測、時間帯別売上(グラフ/リストタブ) |
| 仕入れ | `/stock` | 在庫ゲージ(赤黄緑)、注文ボタン→トースト通知 |
| シフト | `/shift` | 来週のシフト表、「このシフトでOK」→トースト通知 |
| メニュー | `/menu` | 4象限分類、退場候補、ダイナミックプライシング提案→トースト通知 |

**ホーム画面の操作:**
- 売上数字 → 3〜6秒ごとにリアルタイムで増加(緑フラッシュ+金額表示)
- 「今日の時間帯べつ」→ タップで開閉、「グラフ / リスト」タブ切り替え
- やることカード → タップで各ページに遷移
- 下部ミニKPI(リピーター/口コミ/テイクアウト)→ タップで各詳細ページへ

## 全ロール共通ページ

| ページ | パス | 内容 |
|---|---|---|
| おしらせ | `/notifications` | ロール別通知一覧 + LINE通知プレビュー。ベルアイコンから遷移 |
| 顧客分析 | `/customers` | リピート率、LTV、セグメント分析。経営→詳細、店長→シンプル |
| デリバリー | `/delivery` | チャネル別P/L(イートイン/テイクアウト/UberEats/出前館/自社) |
| 口コミ | `/reviews` | 評価推移、感情分析、キーワード、悪い口コミアラート |
| 販促 | `/promotions` | キャンペーンROI、クーポン利用率、チャネル別広告費用対効果 |
| ロス管理 | `/waste` | 食材ロス推移、カテゴリ別内訳、エリア/店舗別比較 |

## インタラクション一覧

| 操作 | 場所 | 動き |
|---|---|---|
| タブ切り替え | EBITDA、P/L、店舗くらべ、時間帯別 等 | タブ押下でコンテンツがフェードイン |
| 展開/折りたたみ | 各セクション(▼マーク) | タップでスライドアニメーション開閉 |
| ドリルダウン | エリア→店舗、店舗一覧 | タップで配下データが展開 |
| ボタン押下 | 注文する、シフトOK、価格変更 等 | トースト通知(画面下部に2秒表示) |
| ライブカウンター | 店長ホームの売上 | 3〜6秒ごとに金額が増加+緑フラッシュ |
| ライブティッカー | 経営/エリアホーム上部 | 4秒ごとにKPIが自動切り替え |
| タップフィードバック | 全ボタン/カード | 押下時に微縮小(scale 0.97) |

## デモ時のおすすめ順序

1. **店長画面から始める**(売上がリアルタイムで動くのが一番インパクトある)
2. **ロールを経営に切り替える**(同じアプリで見える情報がガラッと変わる体験)
3. **EBITDA Impactカードのタブを切り替える**(改善内訳→推移→コスト)
4. **エリアをタップして店舗にドリルダウン**(操作感を見せる)
5. **エリマネに切り替えて◎△✕を見せる**(現場でもわかるUIという証明)
6. **注文ボタンを押してトーストを見せる**(「実際にはここからPOSに連携します」)

所要時間: 3〜5分

## 技術スタック

- Next.js 16 (App Router)
- Tailwind CSS + shadcn/ui
- IBM Plex Sans JP / IBM Plex Mono
- TypeScript
- 全データはモック(mock-data.ts)

---

## 注意事項

- 全てモックデータ。バックエンド・DB・API連携は未実装
- ボタンを押しても実際のデータは変わらない(トースト表示のみ)
- 売上カウンターの増加はランダム生成(リロードでリセット)
- CoCo Spiceは架空のブランド名
